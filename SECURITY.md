# Security policy

[Data Torturing Solutions](https://datatorturingsolutions.co.uk/) runs a small
portfolio of data and directory sites. Most of the estate is private; this is
one of the few public repositories.

## Reporting a vulnerability

Please report privately rather than opening a public issue.

Use **Report a vulnerability** on this repository's Security tab
([direct link](../../security/advisories/new)). That opens a private advisory
visible only to you and the maintainer.

If you would rather not use GitHub, get in touch via
<https://datatorturingsolutions.co.uk/>.

## What to expect

This is a one-person operation, so there is no on-call rota. What is committed:

- acknowledgement within **3 working days**
- an assessment, and either a fix or an explanation of why not, within **30 days**
- credit in the published advisory, if you want it

## Scope

In scope: the contents of this repository and the service it deploys.

Out of scope:

- anything requiring access to an account you do not control
- raw scanner output with no demonstrated impact
- missing hardening headers with no exploitable consequence
- denial-of-service or volumetric testing — please don't

## Please don't

Access, modify or retain data that isn't yours, degrade the service for anyone
else, or run destructive tests. Find it, report it, stop there.
